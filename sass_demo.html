📋 Bảng Tra Cứu Các Lệnh SASS CLI Trọng Tâm

Tác vụ Cú pháp lệnh Mục đích / Giải thích
1. Cài đặt toàn cục npm install -g sass Cài đặt Dart Sass vào môi trường máy tính để dùng ở mọi thư mục
2. Kiểm tra phiên bản sass --version Xác nhận SASS đã sẵn sàng hoạt động trong Terminal
3. Biên dịch 1 tệp đơn sass styles.scss styles.css Chuyển đổi tệp styles.scss thành styles.css sẵn sàng cho web
4. Chế độ Watch (1 tệp) sass styles.scss styles.css --watch Tự động lắng nghe thay đổi và cập nhật CSS tức thì khi lưu SCSS
5. Biên dịch cả thư mục sass scss/:css/ --watch Biên dịch toàn bộ thư mục scss/ sang thư mục css/ trong thời gian thực
6. Nén tối ưu dung lượng sass scss/:css/ --style=compressed Nén tối đa CSS đầu ra cho môi trường Production (tải trang siêu nhanh)
