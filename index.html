[Thực hành] Sử dụng Box Model 1

Minh họa trực quan mô hình hộp (Box Model): Content, Padding, Border, Margin

Content demo box

Cách tính tổng chiều rộng của phần tử (Total Width):

Total Width = width + padding(left+right) + border(left+right) + margin(left+right)
            = 200px + (35px + 35px) + (20px + 20px) + (25px + 25px)
            = 200px + 70px + 40px + 50px = 360px
Thành phần Box Model Khai báo CSS Kích thước đóng góp (Ngang)
Content (Nội dung) width: 200px; 200px
Padding (Khoảng đệm) padding: 35px; (màu lightseagreen) 35px (trái) + 35px (phải) = 70px
Border (Đường viền) border: 20px dashed indianred; 20px (trái) + 20px (phải) = 40px
Margin (Lề ngoài) margin: 25px; (khoảng trống ngoài) 25px (trái) + 25px (phải) = 50px
TỔNG CHIỀU RỘNG THỰC TẾ CHIẾM CHỖ 360px
