📋 Bảng Phân Tích Các Class Bootstrap 5 Sử Dụng Trong Navbar

Class / Thuộc tính Vị trí Mô tả tác dụng
navbar-expand-lg Thẻ <nav> Chỉ mở rộng menu ngang từ màn hình Large (≥ 992px), dưới kích thước này sẽ thu gọn thành nút icon
navbar-dark bg-dark Thẻ <nav> Thiết lập nền tối (dark background) và màu chữ sáng tương phản phù hợp
navbar-brand Thẻ <a> Định dạng logo / tên thương hiệu của website
navbar-toggler Thẻ <button> Nút bấm mở/đóng menu điều hướng trên thiết bị di động
data-bs-toggle="collapse" Thuộc tính nút Kích hoạt tính năng thu gọn/mở rộng bằng Bootstrap JavaScript
dropdown-toggle Thẻ <a> Tạo mũi tên chỉ xuống và kích hoạt danh sách menu con khi bấm vào
