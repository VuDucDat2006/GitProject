[Bài tập] Nhúng CSS vào trang HTML

Thực hành áp dụng 3 cách nhúng CSS: Inline Style, Internal Style và External Style

Phần 1: Inline Style (CSS Nội dòng)

style="..."

Tiêu đề với Inline Style (Xanh dương)

Đây là đoạn văn được đổi màu đỏ trực tiếp bằng thuộc tính style nội dòng: style="color: #dc2626;".

<h1 style="color: #2563eb;">Tiêu đề...</h1>
<p style="color: #dc2626;">Đoạn văn...</p>

Phần 2: Internal Style (CSS Nội bộ)

<style> trong <head>

Tiêu đề với Internal Style (Xanh lá)

Đây là đoạn văn được đổi màu cam bằng bộ chọn CSS định nghĩa trong thẻ <style> ở phần <head>.

<style>
  .internal-title { color: #059669; }
  .internal-text { color: #d97706; }
</style>

Phần 3: External Style (CSS Ngoại tuyến)

<link rel="stylesheet" href="style.css">

Tiêu đề với External Style (Tím)

Đây là đoạn văn được đổi màu xanh da trời thông qua việc liên kết với tệp style.css riêng biệt bên ngoài.

<link rel="stylesheet" href="style.css">
/* File style.css */
.external-title { color: #7c3aed; }
.external-text { color: #0284c7; }
