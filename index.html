📊 So Sánh Kiến Trúc: Trước và Sau Khi Chuyển Đổi

Từ 1 tệp CSS nguyên khối đơn lẻ, chúng ta đã chuyển đổi thành 4 thư mục chuẩn modular:

❌ Trước: CSS Nguyên Khối (styles.css)

body {
  font-family: Arial, sans-serif;
  color: #333;
  background: #f4f4f4;
}
.container { width: 80%; margin: 0 auto; }
.button {
  background: blue; color: white;
  padding: 10px 20px; border-radius: 5px;
}
.card {
  border: 1px solid #ddd; padding: 20px;
  box-shadow: 2px 2px 10px rgba(0,0,0,0.1);
}

✔ Sau: SASS Modular (main.scss)

// abstracts/
$primary-color: blue;
$border-color: #ddd;
@mixin button-style($bg) { ... }
@mixin box-shadow { ... }

// base/ & layout/ & components/
body { color: $text-color; }
.container { width: 80%; }
.button { @include button-style($primary-color); }
.card { @include box-shadow; }

📂 Cấu Trúc Thư Mục Chuẩn SASS Đã Hoàn Thành

📁 abstracts/
  ├── _variables.scss   (Lưu $primary-color, $text-color, $border-color...)
  └── _mixins.scss     (Chứa @mixin button-style, @mixin box-shadow)
📁 base/
  └── _global.scss     (Định dạng thẻ body toàn cục)
📁 layout/
  └── _container.scss  (Định dạng khung bao .container)
📁 components/
  ├── _buttons.scss    (Định dạng lớp .button)
  └── _cards.scss      (Định dạng lớp .card)
📄 main.scss           (Nhập toàn bộ partials theo đúng thứ tự)
