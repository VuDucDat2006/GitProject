Bí Quyết Xây Dựng Bố Cục Web Đột Phá Bằng CSS Grid Layout

✍️ Tác giả: Vũ Đức Đạt (VuDucDat2006) 📅 Ngày xuất bản: 13/10/2026 ⏱️ Thời gian đọc: 5 phút

CSS Grid Layout là hệ thống lưới hai chiều (2D) mạnh mẽ nhất từng được giới thiệu trong ngôn ngữ CSS. Khác với Flexbox (hệ thống dàn trang một chiều theo hàng hoặc cột), CSS Grid cho phép chúng ta chia giao diện trang web thành cả hàng (rows) và cột (columns) cùng lúc.

💡 Tại sao nên sử dụng grid-template-areas?

Bằng cách đặt tên cho từng khu vực giao diện như header, nav, main, sidebar, và footer, cấu trúc CSS trở nên trực quan như một bản vẽ kiến trúc: 

grid-template-areas:
    "header  header"
    "nav     nav"
    "main    sidebar"
    "footer  footer";

📱 Cơ chế thích ứng tự động (Responsive):

  • Màn hình Desktop (> 768px): Nội dung chính (chiếm 1fr) và Sidebar (cố định 300px) nằm cạnh nhau song song, Header, Nav và Footer trải dài toàn bộ chiều ngang.
  • Màn hình Mobile (≤ 768px): Toàn bộ 5 khối tự động chuyển về 1 cột dọc (1fr), xếp theo thứ tự Header → Navigation → Main Content → Sidebar → Footer, tối ưu thao tác vuốt cuộn trên smartphone.
