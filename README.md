# GitProject

Dự án thực hành các thao tác cơ bản với Git và GitHub (CodeGym).

## Nhánh: `simple-table-practice`
Bài tập: **[Thực hành] Tạo bảng đơn giản với tiêu đề và dữ liệu trong HTML**.

### Các thẻ HTML tạo bảng đã sử dụng:
1. `<table>`: Phần tử bao ngoài định nghĩa bảng dữ liệu (`border="1"`).
2. `<tr>`: (*Table Row*) Định nghĩa từng hàng của bảng.
3. `<th>`: (*Table Header*) Tiêu đề của cột (mặc định in đậm và căn giữa). Các cột: *Họ và Tên*, *Tuổi*, *Lớp*.
4. `<td>`: (*Table Data*) Ô chứa nội dung dữ liệu của từng học sinh.
