# GitProject

Dự án thực hành các thao tác cơ bản với Git, GitHub và HTML Form cơ bản (CodeGym).

## Nhánh: `simple-form-exercise`
Bài tập: **[Bài tập] Tạo form đơn giản**

### Nội dung thực hành:
#### Phần 1: Tạo form cơ bản
- Họ và tên: `yourname`
- Email: `email`
- Sở thích: `hobby` (danh sách checkbox)
- Nút Submit: "Gửi thông tin"
- Nút Reset: "Nhập lại"

#### Phần 2: Tạo form đăng ký học viên
- Họ và tên: `fullname`
- Email: `email`
- Số điện thoại: `phone`
- Ngày sinh: `birthday` (date input)
- Giới tính: `gender` (radio: Nam, Nữ, Khác)
- Địa chỉ: `address` (textarea)
- Khóa học: `course` (select: HTML & CSS, JavaScript, Java, Python)
- Hình thức học: `study_type` (radio: Online, Offline)
- Sở thích: `hobby` (checkboxes)
- Ghi chú: `note` (textarea)
- Nút "Đăng ký" (Submit) và "Nhập lại" (Reset)

### Danh sách file trong nhánh:
- `index.html`: Giao diện tổng hợp đầy đủ cả Phần 1 và Phần 2 với CSS hiện đại, trực quan.
- `part1_form.html`: Form độc lập Phần 1.
- `part2_form.html`: Form độc lập Phần 2 (Đăng ký học viên).
