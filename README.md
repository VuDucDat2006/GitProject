# GitProject

Dự án thực hành các thao tác cơ bản với Git và GitHub (CodeGym).

## Nhánh: `text-formatting`
Bài tập: **Định dạng văn bản với các thẻ HTML và thuộc tính CSS nội tuyến (Inline CSS)**.

### Các thẻ và thuộc tính CSS đã sử dụng:
1. **Thẻ tiêu đề & đoạn văn**:
   - `<h1>`: Tiêu đề chính, áp dụng `style="color: blue; text-align: center;"`
   - `<p>`: Đoạn văn bản, áp dụng `font-size: 18px;`, `color: red;`, `text-align: center; font-family: Arial, sans-serif;`
2. **Thẻ định dạng chữ**:
   - `<b>`: Chữ in đậm
   - `<i>`: Chữ in nghiêng
   - `<u>`: Chữ gạch chân
3. **Danh sách tùy chỉnh**:
   - `<ul>` và `<li>`: Danh sách không thứ tự, áp dụng `style="color: green; font-weight: bold;"`
