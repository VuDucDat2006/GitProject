# GitProject

Dự án thực hành các thao tác cơ bản với Git và GitHub (CodeGym).

## Cấu Trúc Dự Án
```plaintext
GitProject/
├── README.md
├── halong_bay.html       # Bài thực hành: Vịnh Hạ Long - Kỳ quan Thiên nhiên (h1, p, img, a)
└── source/
    ├── index.html        # Trang chủ Welcome to Index Page
    ├── news.html         # Trang tin tức Welcome to News Page
    └── halong_bay.html   # Bản sao trong source
```

## Các Nhánh (Branches)
- `main`: Nhánh chính chứa khung dự án ban đầu.
- `halong-bay`: Nhánh thực hành bài tập HTML Vịnh Hạ Long với đầy đủ thẻ `<h1>`, `<p>`, `<img>`, `<a>`.
