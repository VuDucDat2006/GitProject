# GitProject

Dự án thực hành các thao tác cơ bản với Git, GitHub và các phương pháp nhúng CSS (CodeGym).

## Nhánh: `css-embedding-methods`
Bài tập: **[Bài tập] Nhúng CSS vào trang HTML**

### Mục tiêu:
Luyện tập và so sánh 3 phương pháp nhúng CSS vào trang web để thay đổi màu sắc văn bản (tiêu đề `<h1>` và đoạn văn `<p>`):
1. **Phần 1: Inline-style (CSS nội dòng)**:
   - Sử dụng trực tiếp thuộc tính `style="..."` trên từng phần tử HTML.
   - File: `part1_inline.html`.
2. **Phần 2: Internal-style (CSS nội bộ)**:
   - Sử dụng cặp thẻ `<style>...</style>` đặt trong thẻ `<head>` của tài liệu HTML.
   - File: `part2_internal.html`.
3. **Phần 3: External-style (CSS ngoại tuyến)**:
   - Tạo file `style.css` riêng biệt và liên kết qua thẻ `<link rel="stylesheet" href="style.css">`.
   - File: `part3_external.html` và `style.css`.

### Danh sách file trong nhánh:
- `index.html`: Giao diện tổng hợp minh họa trực quan cả 3 phương pháp.
- `part1_inline.html`: File độc lập Phần 1.
- `part2_internal.html`: File độc lập Phần 2.
- `part3_external.html`: File độc lập Phần 3.
- `style.css`: File CSS ngoại tuyến.
