# GitProject

Dự án thực hành các thao tác cơ bản với Git và GitHub (CodeGym).

## Nhánh: `heading-paragraph-practice`
Bài tập: **Luyện tập sử dụng các thẻ tiêu đề (heading) và đoạn văn (paragraph) trong HTML**.

### Yêu cầu bài tập:
- Tạo tệp `index.html`.
- Thẻ `<h1>`: *"Chào mừng đến với trang web của tôi"*.
- Thẻ `<h2>`: *"Giới thiệu bản thân"*.
- Thẻ `<p>`: Mô tả về sở thích cá nhân.
- Thẻ `<p>`: Mô tả về mục tiêu học lập trình.

### Cấu Trúc Thư Mục
```plaintext
GitProject/
├── README.md
├── index.html        # Trang web cá nhân thực hành thẻ h1, h2, p
└── source/
    ├── index.html
    └── news.html
```
