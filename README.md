# GitProject

Dự án thực hành các thao tác cơ bản với Git, GitHub và CSS (CodeGym).

## Nhánh: `personal-website-css`
Bài tập: **[Thực hành] Tạo trang web cá nhân với CSS**

### Mục tiêu:
- Nhúng CSS ngoại tuyến vào tài liệu HTML bằng thẻ `<link rel="stylesheet" href="style.css">`.
- Áp dụng các bộ chọn CSS (`body`, `header`, `.profile`, `.avatar`, `ul`, `table`, `th`, `td`, `footer`).
- Định dạng đường viền (border) và bo tròn ảnh đại diện (`border-radius: 50%`).
- Điều chỉnh màu nền (`background-color: #4CAF50`, `#f5f5f5`, `#ddd`) và màu chữ (`color`).
- Trình bày danh sách sở thích và bảng thông tin liên hệ gọn gàng với `border-collapse: collapse;`.

### Cấu trúc file:
- `index.html`: Cấu trúc trang web cá nhân.
- `style.css`: File định dạng giao diện CSS.
- `avatar.jpg`: Ảnh đại diện lập trình viên.
