# GitProject

Dự án thực hành các thao tác cơ bản với Git và GitHub (CodeGym).

## Nhánh: `html-links-practice`
Bài tập: **Luyện tập sử dụng thẻ liên kết (`<a>`) để điều hướng trong HTML**.

### Yêu cầu bài tập:
1. Tiêu đề `<h1>`: *"Liên kết yêu thích của tôi"*.
2. Danh sách không thứ tự (`<ul>`) chứa ít nhất 3 liên kết dẫn đến các trang web khác nhau (Google, YouTube, GitHub, Wikipedia).
3. Một liên kết mở trong tab mới với `target="_blank"`.
4. Một liên kết đến file HTML khác trong cùng thư mục (`about.html`).
5. Một liên kết đến email cá nhân (`mailto:`).
6. Tệp `about.html` với nội dung đơn giản và có link quay về `index.html`.

### Cấu Trúc Thư Mục
```plaintext
GitProject/
├── README.md
├── index.html        # Trang web chính chứa các loại liên kết
├── about.html        # Trang giới thiệu nội bộ liên kết cùng thư mục
└── source/
    ├── index.html
    └── news.html
```
