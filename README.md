# GitProject

Dự án thực hành các thao tác cơ bản với Git và GitHub (CodeGym).

## Nhánh: `html-lists`
Bài tập: **Luyện tập sử dụng các thẻ danh sách trong HTML (`<ul>`, `<ol>`, `<li>`, danh sách lồng nhau)**.

### Nội dung thực hành:
1. **Danh sách không có thứ tự (`<ul>`)**:
   - Hiển thị danh sách mua sắm với các dấu chấm đầu dòng (`•`).
   - Các mục: Sữa, Bánh mì, Trứng, Rau củ.
2. **Danh sách có thứ tự (`<ol>`)**:
   - Hiển thị danh sách công việc cần làm được đánh số thứ tự (1, 2, 3, 4).
   - Các mục: Dọn dẹp nhà cửa, Đi chợ, Viết báo cáo, Học lập trình HTML.
3. **Danh sách lồng nhau (Nested List)**:
   - Thẻ `<ul>` nằm bên trong mục `<li>` của thẻ `<ol>` để chia nhỏ công việc "Dọn dẹp nhà cửa" thành Quét nhà, Rửa chén, Giặt đồ.
