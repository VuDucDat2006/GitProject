# GitProject

Dự án thực hành các thao tác cơ bản với Git, GitHub và CSS Màu nền / Ảnh nền (CodeGym).

## Nhánh: `css-background-practice`
Bài tập: **[Bài tập] Tạo trang web với màu nền và ảnh nền**

### Mục tiêu:
- Thiết lập màu nền `background-color` cho trang web (`body { background-color: #f1f5f9; }`).
- Thêm tiêu đề `<h1>`: "Chào mừng đến với trang web của tôi".
- Thêm đoạn văn `<p>` mô tả trang web.
- Thêm khối `<div>` chứa nội dung quan trọng với ảnh nền (`background-image: url('background.jpg')`).
- Căn giữa nội dung trong khối `<div>` (`display: flex; justify-content: center; align-items: center; text-align: center;`).

### Cấu trúc file:
- `index.html`: Cấu trúc tài liệu HTML.
- `style.css`: Tệp định dạng CSS.
- `background.jpg`: Ảnh nền banner công nghệ hiện đại.
