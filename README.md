# GitProject

Dự án thực hành các thao tác cơ bản với Git, GitHub và Bộ chọn CSS (CodeGym).

## Nhánh: `css-selectors-practice`
Bài tập: **[Bài tập] Sử dụng bộ chọn CSS để định dạng trang web**

### Mục tiêu:
Luyện tập sử dụng đa dạng các bộ chọn CSS (Element, Class, ID, Grouping, Pseudo-classes):
- **Element Selector**: `body` (đổi màu nền trang), `h1`, `p`, `ul`, `li`, `button`.
- **ID Selector**: `#main-heading` (căn giữa tiêu đề `<h1>`), `#btn-action` (nút bấm).
- **Class Selector**: `.card-container`, `.intro-description`, `.hobby-list`, `.hobby-item`, `.hobby-1`, `.hobby-2`, `.hobby-3`.
- **Grouping Selector**: `h1, h2` (nhóm các tiêu đề để định dạng độ đậm font).
- **Pseudo-classes Selector**: `:hover` (hiệu ứng hover đổi màu, nâng nút và bóng mờ), `:active`.

### Cấu trúc file:
- `index.html`: Cấu trúc HTML của trang web.
- `style.css`: Toàn bộ mã CSS định dạng các bộ chọn.
