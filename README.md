# GitProject

Dự án thực hành các thao tác cơ bản với Git, GitHub và HTML cơ bản (CodeGym).

## Nhánh: `company-meeting-schedule`
Bài tập: **[Bài tập] Gộp ô trong bảng với rowspan và colspan**

### Mục tiêu:
- Luyện tập sử dụng `rowspan` và `colspan` để gộp ô trong bảng HTML.
- Trình bày lịch họp công ty một cách khoa học, chuyên nghiệp:
  - Tiêu đề chính `<h1>`: "Lịch họp công ty".
  - Các cột: `Ngày`, `Giờ`, `Nội dung cuộc họp`.
  - Sử dụng thuộc tính `rowspan` để gộp ô trong cột Ngày khi có nhiều cuộc họp trong cùng một ngày (Thứ Hai, Thứ Ba, Thứ Năm, Thứ Sáu).
  - Sử dụng thuộc tính `colspan` để gộp ô khi cuộc họp kéo dài nhiều giờ hoặc diễn ra cả ngày (Thứ Tư, chiều Thứ Sáu).

### Cấu trúc file:
- `index.html`: File HTML chính hiển thị lịch họp công ty.
- `meeting_schedule.html`: File dự phòng tương đương.
